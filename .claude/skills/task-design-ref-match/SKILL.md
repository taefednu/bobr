# Сделать как на рефе

Причина порядка: вёрстка «на глаз» по картинке каждый раз даёт экран, который потом правят десятками
мелких правок. Шаги не пропускаются.

## Шаги

1. **Дизайн-система до кода.** Выпиши объекты с картинки (карточки, кнопки, плашки, лепёшка, дома, пустые
   состояния) и для каждого — каким токеном `DESIGN.md`/`globals.css` и каким существующим компонентом он
   делается. Новое — только если такого нет, с причиной.
2. **Замер и план — числами, в файле, до реализации** (`docs/design-refs/<экран>.plan.md`):
   ```bash
   python3 -c "from PIL import Image; im=Image.open('docs/design-refs/X.png'); print(im.size); im.crop((x1,y1,x2,y2)).save('/tmp/crop.png')"
   ```
   Положение и размер каждого блока в % ширины экрана, отступы, цвета пикселей (`im.getpixel`). Сверить с
   настоящим экраном той же ширины: `npm run ui-check -- /route --boxes '<селекторы>'` (desktop и phone).
3. **Реализация блоком целиком**, не по одному элементу: все расхождения списком → одна правка → один снимок.
   Геометрия — константой в одном месте; линия SVG и элементы CSS, которые должны совпасть, — из одной формулы.
4. **Сверка наложением** снимка на реф той же ширины + таблица «блок / макет % / страница % / Δ %». Δx, Δw,
   сдвиг y — от ширины контента; **Δh — от высоты этого блока на макете**. Больше 5 % по блоку — не готово.
   Попиксельный diff не метрика: в макете выдуманные данные и чужой шрифт.

## Всегда вместе с этим

- Каждое число, знак и картинка на экране приходят из данных; одна величина везде одинакова.
- Строки — i18n сразу в `uz.json` и `ru.json`; uz обычно длиннее — проверь `--lang uz`.
- Поиск хардкода по итоговому диффу (цвета, тексты, пиксели вне токенов).
- Скоуп — только названный экран. Соседний не трогать.
- «Готово» без таблицы замеров и снимка наложения не говорить.

## Частые ошибки

- Δ% не от того знаменателя (высоту делили на ширину — 13,5 % превратились в 4,1 %).
- Микро-итерации по одному элементу — версии множатся, разница остаётся.
- Сгенерированные картинки вместо аккуратного CSS/SVG — сначала код по рефу, арт только по просьбе.
