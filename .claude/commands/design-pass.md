Дизайн-проход по экрану `$ARGUMENTS`.

1. Загрузи скилл `bobr-design` (старшинство, бан-лист, какой скилл когда).
2. Подними dev-сервер, если не поднят (`npm run dev` в фоне), и сними «было»:
   `npm run ui-check -- <route> --full` и `--lang ru --full`. Посмотри PNG сам.
3. Агент `design-critic` по этому route (одна критика, не цикл).
4. Исправь топ-находки, загружая скилл, который назвал критик (`polish`, `layout`, `typeset`, `unslop`,
   `animate`…). Значения — только токены `DESIGN.md` и `lib/motion.ts`; строки — i18n в оба языка.
5. Сними «стало» теми же командами; агент `ui-verifier` по route.
6. `npm run verify`.

Отчёт: таблица «находка / что сделал / скилл / подтверждено снимком?», затем «было / стало» картинками
(SendUserFile, display render), затем что осталось и вопросы владельцу.
