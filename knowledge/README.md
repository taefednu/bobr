# Bobr — база знаний

Хаб. Начало сессии: этот файл → [[sprint]] (раздел «Сейчас»). Дальше — по таблице, грепом, не подряд.
Источник правды о продукте — `docs/BOBR_SPEC.md`; здесь — то, чего в спеке нет: где лежит код, что решили
и почему, где стоит работа, на чём обожглись. История — `git log`, отдельного журнала нет.

## Маршрутизация

| Вопрос | Читай |
|---|---|
| Что делаем сейчас, следующий шаг, промпт сессии | [[sprint]] |
| Что осталось сделать (этапы, резка) | [[backlog]] |
| Что за продукт, механики, где в спеке | [[product]] |
| Где лежит файл, как устроен код, команды | [[structure]] |
| Почему так (модели, стек, дизайн, вне спеки) | [[decisions]] |
| Грабли окружения и кода, уже пойманные | [[lessons]] |
| Дизайн | `DESIGN.md`, `PRODUCT.md`, скилл `bobr-design` |
| Что не получилось и обошли | `BLOCKERS.md` (если есть) |

## Правило синхронизации

База знаний правится **в том же коммите**, что и код, который её меняет:
- закончил шаг/этап → переписать раздел «Сейчас» в [[sprint]], отметить в [[backlog]];
- принял решение, которого нет в спеке → строка в [[decisions]] с причиной;
- появился модуль, таблица, маршрут, команда → [[structure]];
- обжёгся и это повторится → [[lessons]] (а лучше тест или хук).
Расхождение базы с кодом — баг: правь запись, а не обходи её.
