# Bobr v3: мобильное приложение, 4 экрана

Решение владельца 18.11. Эталоны: `1-home.png`, `2-house.png`, `3-chat.png`, `4-profile.png`. Исходный реф владельца:
`refs/owner-*.png`, берём его композицию (главный экран и экран с домом, правый слайд не берём), цвета наши светлые и тёплые.
Делаем только телефон 390 px. Десктоп потом: на широком экране просто центрируем колонку 390–430 px.

Для этих экранов v3 важнее `DESIGN.md` v1: **нет ink-обводок и ink-уступов**, мягкий объём, градиенты, тени. Спека продукта и правила
безопасности остаются главными. Запреты в силе: монеты, HP, серии на экране, рейтинги, магазины, фиолет и неон как акцент.

## Экраны и данные

Все данные считает сервер, токен сессии обязателен. Все числа на экране приходят из данных. Строки через i18n в `uz` и `ru`, префиксы `home.`,
`house.`, `chatv3.`, `profile.`, `nav.`.

### Таб-бар (общий)
Четыре вкладки: Главная `/home`, Мой дом `/house`, Чат `/chat`, Профиль `/profile`. Рамка `measure/*.json` → `nav`, активная кнопка
круглая `teal`, 56 px, выступает из полосы, неактивные иконки в коричневом контуре. Центры вкладок равномерно по полосе; активная
кнопка стоит в своей вкладке. На экране дома и в чате бара нет, как на эталоне: там кнопка «назад».

### Главный `/home`
`home:view {token}` → `{ next: {topic, title, percent} | null, taught: number, plan: {done, total} }`. `percent` = доля тем плана со статусом
`solved_self` или `taught_bobr`, целое. Приветствие без имени. Круги: Ustoz → `/chat?who=ustoz`, Bobr → `/chat?who=bobr`, Мой путь → `/plan`, Научи →
последняя тема `solved_self` или `/house`. Баннер: тема `next`, кольцо с `percent`, стрелка → старт урока (`mahalla:startLesson`). `next = null`: баннер «Научи Bobr».
«Советуем»: две карточки в чаты.

### Мой дом `/house`
Первая версия упрощена решением владельца 18.11.

`house:view {token}` → `{ levels: {n, topic, title, state: "done"|"current"|"next"|"review", canStart}[] }`.
- Уровни: первые 6 тем плана, которые реально стартуют через `mahalla:startLesson`, в порядке плана.
- Экран: одна PNG `house-island` с домом и камнями, поверх шесть кнопок по координатам `level1…6`. Номер и состояние камня рисует код.
- Нажатие: тема стартует, ребёнок попадает в урок. Уровня нет или старт не удался: нижняя шторка со спокойным текстом.
- Состояний `life`, потухшего дома и отдельных спрайтов в этой версии нет.

### Чат `/chat`
Текущие `chat:view`, `chat:send`, переключатель партнёра через `?who=`. Шапка: назад, аватар, имя, строка «ИИ-учитель, может ошибаться» (для Bobr своя). Пузыри по эталону, чипы
«Подскажи» и «Другой пример» отправляют обычное сообщение, поле с кнопкой внизу. Закрытые состояния, кризис и запасные реплики из нынешнего `ChatView` не теряются.
Лепёшка в пузыре: `chat:view` добавляет к реплике `visual: {type: "pie", fraction} | null`, код берёт первую дробь из проверенного текста; компонент рисует лепёшку из дроби.

### Профиль `/profile`
`profile:view {token}` → `{ name|null, grade|null, lang, goal, topics: {done, total}, taught }`; `profile:setLang {token, lang}`. Имя только показываем на экране: в LLM, turns и логи не идёт
(`tests/displayNameGuard.test.ts`). Без имени подпись `profile.noName`. Строки: Язык (шторка uz/ru), Звук (локальная настройка), Цель (шторка, `goal:set`), Что видят родители (шторка с текстом). Заметка «Bobr и Ustoz — ИИ и могут ошибаться».

## Не сломать
Демо-путь цель → диагностика → план → дом → урок → «Научи Bobr», `session:*`, кризисный экран, все safety-проверки чата. После плана ребёнок попадает на `/home`.
Экраны урока, плана, диагностики и входа в этой волне получают только токены фона и кнопок v3, если останется время; их переделка следующая.
