## Вне таблицы

- **Баг для сессии teach (P0, вывод из кода, на экране не воспроизводил):** `TeachView.tsx:87` даёт обёртке `lg:-translate-x-1/2`, а `CrisisOverlay` с `fixed inset-0` стоит внутри неё (`:202`). При ширине от 1024 px кризисный экран будет привязан к обёртке и может не закрыть окно. Варианты: `createPortal` в `document.body` внутри `CrisisOverlay` либо вынос обёртки через margin, как в D1. В таблицу не внесено: это зона teach, а кризисный экран по CLAUDE.md §2 меняется только отдельной задачей.
- **Для владельца /parent:** единственное живое использование серого каркаса — `app/parent/dashboard.tsx:8`, импорт `AiBadge` из `components/skeleton/Shell.tsx`. Там `text-sm`, мельче label, а это запрет из `bobr-design`. Правка: импорт из `@/components/child/AiBadge`, после неё `Shell.tsx` можно удалить.
