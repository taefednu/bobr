# Выкатка Bobr

Всё нужное для запуска уже лежит в репозитории. Сама выкатка идёт из последнего коммита и новых коммитов не создаёт.

Есть три части: база и функции в Convex Cloud, сайт и бот родителя. Сайт можно поставить на свой сервер или на Vercel. Боту нужен постоянно работающий процесс, поэтому для него нужен сервер с Docker.

## Подготовка

1. Создай проект в Convex Cloud и production deploy key.
2. Скопируй настройки и заполни их:

```bash
cp .env.production.example .env.production
```

3. Проверь код:

```bash
bash scripts/deploy.sh check
```

## Запуск

Сначала функции и настройки Convex:

```bash
bash scripts/deploy.sh convex
```

Затем сайт и бот на своём сервере. Домен должен указывать на сервер, порты 80 и 443 открыты, HTTPS выпустит Caddy:

```bash
bash scripts/deploy.sh server
```

Или только сайт на Vercel, без привязки репозитория:

```bash
bash scripts/deploy.sh vercel
```

Для варианта с Vercel укажи выданный адрес в `PUBLIC_APP_URL` и снова запусти шаг `convex`.

## После запуска

Открой сайт в чистом окне и пройди путь: вход, цель, диагностика, план, главный экран, урок с камня, ответ Ustoz, чат.
Страницы `/dev/*` и `/parent/preview` должны отвечать 404.

`DEMO_ALLOW_ANON=1` открывает вход любому посетителю. Каждый такой посетитель может тратить ключ Claude, поэтому включай этот режим только на время показа и поставь лимит расходов у провайдера.
