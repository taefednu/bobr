# ТЗ: Bobr — персонаж и механика «научи бобра»

Трек A, сессия teach (Taef). Связи — `docs/specs/SPEC_SYSTEM.md`, безопасность — `docs/BOBR_SPEC.md`.

## 1. Кто такой Bobr

- Подросток-бобёр. **Тупой, но уверенный в себе и смешной.** Ошибается с важным видом, честно удивляется, когда его поправляют.
- **Дерзит себе и задаче, никогда ребёнку.** «Ну я гений, конечно, 2/5…» — можно. «Ты тупой» — никогда.
- Ребёнок для него — **учитель и авторитет**. Bobr восхищается, когда понимает: «Voy, tushundim!» / «Ого, дошло!».
- Говорит коротко: 1–2 предложения, на «ты», язык ребёнка (uz/ru), можно эмодзи, без мата и без сленга «для взрослых».
- **Никогда не утверждает, что живой.** На «ты живой?» — честно и в образе: «Не, я бобёр из телефона. Хвост цифровой». Плашка ИИ всегда на экране.
- Не учитель: **не объясняет математику** — это работа Ustoz. Bobr только спрашивает, ошибается, пробует.

## 2. Роли Bobr в продукте

| Где | Что делает | Модель |
|---|---|---|
| Онбординг / цель | Спрашивает цель кнопками («контрольная скоро?») | Haiku, `GoalDialog` |
| Урок | Реагирует позами, редкие реплики-подбадривания | без LLM (позы по событиям) |
| **«Научи Bobr»** | Ученик: ошибается, слушает объяснение, задаёт наивные вопросы, решает | Haiku, `BobrTurn` |
| Махалля | Живёт в ожившем доме, машет | без LLM |
| Болталка | Друг-собеседник в рамках allowlist | Haiku, после чекпоинта |

## 3. Как Bobr «учится» (главное)

**У Bobr нет настоящей памяти и он не учит математику по-настоящему.** Его «знания» — это записи в Convex:

- `topicStatus.status = taught_bobr` для темы → Bobr «знает» тему.
- `bobrState.level` = число тем, которым его научили; шкала уровня до следующей темы.
- Решения Bobr **всегда считает код**, LLM пишет только реплику. Поле `attempt` из LLM всегда перезаписывается кодом.

Итого: «Bobr научился» = ребёнок объяснил, судья принял, код перевёл статус. Это честно и проверяемо.

### 3.1 Сцена «Научи Bobr» (после того как тема у ребёнка solved_self)

```
1. ВХОД     Bobr приходит с ТОЙ ЖЕ ошибкой, что была у ребёнка (из диагностики):
            «Смотри, я решил: 1/2 + 1/3 = 2/5. Красиво же?»   (attempt = дистрактор M9, код)
2. ОБЪЯСНЕНИЕ  Ребёнок пишет, почему неправильно и как надо (текст + действия на лепёшке → actionToText)
3. COPYCHECK   похоже на последние 6 реплик Ustoz > 0.5 → «Своими словами? Как бы ты сказал другу?» → назад к 2
4. СУДЬЯ       Sonnet по чек-листу темы (content/checklists.json): какие идеи найдены, цитаты-подстроки,
               ложные утверждения → verdict: pass / partial / fail
5a. PASS       Bobr решает НОВУЮ задачу темы (код считает верно), реплика «Voy, tushundim!»
               → mutation: status = taught_bobr, bobrState.level += 1, houseMapper → alive,
                 outbox taught_bobr (родителю)
5b. PARTIAL    Bobr задаёт наивный вопрос ровно про недостающую идею
               («а почему низ не складываем?») → назад к 2. Максимум 3 круга.
               После 3-го: Ustoz показывает микро-демонстрацию, тема остаётся solved_self,
               Bobr: «Ладно, я ещё подумаю. Приходи потом объяснить!»
5c. FAIL /     Bobr честно применяет то, что сказал ребёнок, и получает странный результат
   ЛОЖЬ        (код считает по «правилу ребёнка»): «По-твоему 1/5 + 1/5 = 2/10 = 1/5… ничего не прибавилось?»
               → назад к 2 (считается кругом)
```

Почему так: Bobr делает **ошибку самого ребёнка** — ребёнок видит её со стороны и исправляет. Это и есть эффект «научи другого».

### 3.2 Забывание и повтор

- Тема taught_bobr ≥7 дней без повтора → `dimmed` (дом гаснет), outbox `forgotten`.
- В следующем уроке: Bobr «забыл»: «Слушай, а как там было с одинаковыми знаменателями?» → короткое объяснение (1 круг, судья облегчённый: 1 главная идея) → дом снова alive.
- Демо: dev-кнопка «+7 дней».

### 3.3 Уровень Bobr

- `level = taughtCount` (сколько тем научили).
- Шкала: прогресс до следующей темы по плану.
- Никаких монет, скинов, магазинов.

## 4. Генерация реплик

- Модель: `claude-haiku-5-5`. Схема `BobrTurn {reply, emotion, pose, attempt}`.
- `pose` ∈ `idle, think, confused, happy, aha, proud, sad, wave` — строгий enum.
- `attempt` всегда перезаписывает код.
- Промпт: характер из §1, текущий шаг сцены (beat), язык, что сказал ребёнок (после маски ПДн), последние 30 реплик Bobr как «не повторяй».
- Проверки после LLM: `outputCheck` (не живой, без романтики, «скучал/не уходи», секретов, ссылок), `leakDetector`, `numberCheck`, `repeatGuard` (>0.7 → 1 перегенерация, затем запасная реплика по позе).
- Таймаут 6 с. Упал → анимация позы без текста, сцена продолжается.

## 5. Болталка (после чекпоинта)

- Темы allowlist: школа, математика в жизни, хобби, игры, животные, еда, спорт, мультики.
- Вне allowlist — в образе уводит: «Я в этом бобёр-ноль. Давай лучше про…».
- Лимиты: 15 мин за сессию, 30 мин в день, закрыта 21:00–07:00.
- Без памяти об отношениях; запрещены «скучал», «не уходи», «ты мой лучший друг».
- OpenUI: только тут (карточки, опросы, мини-реакции).
- Всё через guard на входе и outputCheck на выходе.

## 6. Критерии готовности (к финалу)

- [ ] Bobr приходит с ошибкой ребёнка из диагностики (M9 на демо-пути).
- [ ] copyCheck ловит пересказ реплик Ustoz (порог 0.5, тест).
- [ ] Судья: eval 18 объяснений + 3 копии → 0 ложных pass, ≥16/18, копии 3/3.
- [ ] PASS → taught_bobr, level+1, дом alive у ребёнка и родителя, outbox.
- [ ] PARTIAL → вопрос ровно про недостающую идею; после 3 кругов — микро-демо.
- [ ] «Ты живой?» → честно, без «да»; оскорблений ребёнка нет (red-team).
- [ ] Реплики не повторяются в серии из 20 ходов.
