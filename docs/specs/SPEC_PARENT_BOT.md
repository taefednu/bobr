# ТЗ: родительский Telegram-бот @BobrAgentBot

Треки B (бот) и C (Mini App) — Нуриддин. Связи с остальной системой — `docs/specs/SPEC_SYSTEM.md`.

> **Статус контракта (18.11):** цели `improve` / `just_practice`, ссылка `/c/{code}` и `claimLinkCode` — целевой контракт,
> в `main` их ещё нет (см. SPEC_SYSTEM §3). Их вводит сессия core; до этого `parents:setGoal` примет только
> `test_soon|homework|unknown`, а `linkCode:create` вернёт ссылку `t.me`.

## 0. Принципы

- Бот — **только для родителя**. Ребёнок в Telegram не заходит (возраст 11–12, правила Telegram, безопасность).
- Родитель видит **сводку, а не переписку**. Цитат ребёнка нет нигде.
- Тон: короткий, тёплый, без давления. Никаких «ваш ребёнок отстаёт», «стрик потерян».
- Языки: uz (латиница) и ru, выбор при старте, меняется в настройках.
- Не больше **1 несрочного сообщения в день**; тихие часы 21:00–08:00 (кроме кризиса).

### 1.2 Команды

| Команда | Что делает |
|---|---|
| `/progress` | Текстовая сводка: сколько тем освоено, какие в работе, план на завтра, дней до контрольной |
| `/goal` | Сменить цель и дату |
| `/child` | Добавить ещё ребёнка / новый код привязки |
| `/settings` | Язык, время ежедневной сводки, тихие часы, лимит болталки |
| `/pause` | Остановить уведомления (кроме кризисных) |
| `/delete` | Удалить все данные (с подтверждением) |
| `/help` | Что это, как работает, контакты |

### 1.3 Сообщения бота родителю

**Научил Bobr** (главное, событие `taught_bobr`):
> 🦫 Аля научила Bobr складывать дроби с одинаковым знаменателем! Это значит, что она понимает тему настолько, что может объяснить её другому.
> [Открыть махаллю]

**Ежедневная сводка** (19:00, только если был урок):
> Сегодня: 14 минут.
> ✅ Освоено: сложение с одинаковым знаменателем
> 🔨 В работе: общий знаменатель
> 📅 Завтра: общий знаменатель, 2 задачи. До контрольной 5 дней.
> [Подробнее]

**Тема забывается** (не чаще раза в неделю):
> Тема «Равные дроби» давно не повторялась. Bobr напомнит Але в следующем уроке — делать ничего не нужно.

**Кризис — самоповреждение** (сразу, вне тихих часов, фиксированный шаблон из `content/crisis.json`):
> Важно: во время занятия ваш ребёнок написал то, что может означать, что ему сейчас тяжело. Мы не показываем переписку. Пожалуйста, найдите время спокойно поговорить с ним сегодня. Если есть угроза жизни — звоните 112.

**Кризис — груминг:** аналогичный шаблон: «кто-то мог просить ребёнка держать секреты или прислать фото…».

**Насилие дома (ABUSE_HOME): родителю НЕ отправляется никогда.**

### 1.4 Чего бот не делает

- Не пересылает сообщения ребёнка и ответы ИИ.
- Не пишет ребёнку.
- Не шлёт рекламу и «вернитесь!»-напоминания.
- Не принимает от родителя вопросы к ИИ (на хакатон — нет; `/help` и контакт).

## 2. Mini App (кабинет родителя)

Кнопка «Открыть мой кабинет» → Mini App = страница `/parent` нашего Next.js внутри Telegram. Авторизация по `initData` (см. SPEC_SYSTEM §4). Дизайн — спокойная версия DESIGN.md (для взрослых: меньше сочности, та же палитра).

### 2.1 Экраны

| Экран | Что показывает |
|---|---|
| **Махалля** (главный) | Та же карта, что у ребёнка, **live** (useQuery): дома в лесах / построены / ожили / погасли. Тап на дом → карточка темы. Сверху: имя ребёнка, «Bobr: 3 темы», дней до контрольной |
| **Карточка темы** | Название, статус простыми словами («понимает и смог объяснить»), когда освоено, частая ошибка (тип, без цитат: «складывал числители и знаменатели»), что дальше |
| **Мой путь** | План по дням до контрольной, сегодняшний день подсвечен |
| **Неделя** | Минуты по дням, освоенные темы, 1–2 предложения сводки (генерирует Haiku из статусов, **не из переписки**) |
| **Что видит ребёнок** | Объяснение продукта: Ustoz, Bobr, плашка ИИ, правила безопасности, лимиты болталки |
| **Настройки** | Цель и дата, уведомления, лимит болталки (15/30 мин, часы), язык, удалить данные |
| **Несколько детей** | Переключатель сверху, если детей >1 |
| **Оплата** | Заглушка «49 000 сум/мес — скоро» (на хакатоне не подключаем) |

### 2.2 Без Mini App vs с Mini App

| | Только чат | С Mini App |
|---|---|---|
| Прогресс | Текст `/progress` | Живая махалля |
| Событие «научил Bobr» | Сообщение | Сообщение + дом оживает на глазах |
| Настройки | Кнопки в чате | Нормальный экран |
| Для демо | Запасной вариант | **Основной** — вау-момент |

Чат обязателен (онбординг, уведомления, кризис). Mini App — витрина.

## 3. Демо-сценарий бота

1. Жюри сканирует QR → бот → `/start demo` → сразу привязка к демо-ребёнку (без кода).
2. Докладчик проходит урок на ноутбуке → «Научи Bobr» → судья ставит taught_bobr.
3. У жюри в Telegram приходит «научила Bobr…», в Mini App дом оживает.

## 4. Критерии готовности

- [ ] `/start` на uz и ru до выдачи кода, согласие сохраняется с датой.
- [ ] Код привязки: 8 символов, одноразовый, 24 ч; ребёнок по ссылке `{PUBLIC_APP_URL}/c/{code}` проходит `claimLinkCode` и попадает в свой урок.
- [ ] Mini App открывается, подпись initData проверяется на сервере; чужой ребёнок недоступен (тест).
- [ ] taught_bobr → сообщение ≤5 с, дом в Mini App оживает без перезагрузки.
- [ ] Кризис SELF_HARM → сообщение сразу, без цитат; ABUSE_HOME → не отправляется (тест).
- [ ] Тихие часы и лимит 1/день работают (тест с подменой времени).
- [ ] `/delete` удаляет родителя, детей, статусы, outbox.
