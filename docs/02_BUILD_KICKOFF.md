## Этап 0 — каркас (≈1 ч)

1. `convex/schema.ts`: все таблицы из спеки с индексами. Дроби — `v.string()`.
2. `lib/types.ts`: состояния машины, статусы тем, события хода, zod-схемы (UstozTurn, Judge, BobrTurn, OutputCheck, GoalDialog, GuardResult).
3. `content/graph.json`: 10 тем N1–N10 с пререквизитами из спеки, названия ru/uz.
4. `lib/config.ts`: модели, таймауты, лимиты болталки, номера кризиса, `DEMO_MODE`.
5. Скелет UI: роутинг экранов ребёнка (Цель, Диагностика, Махалля, Урок, Научи Bobr, Болталка) и `/parent`. Плашка ИИ на всех экранах чата.

## Этап 1 — детерминированное ядро, с тестами (≈2 ч)

Порядок: `parseAnswer` → `generator` → `leakDetector` → `numberCheck` → `copyCheck` → `repeatGuard` → `planner` → `houseMapper`. Каждый модуль — чистый TS в `lib/` плюс vitest-тесты из спеки. Проверь демо-случаи: `2/5` на `1/2+1/3` даёт misconception M9; «yarim» = 1/2; «0,5» = 1/2; несократимый ввод `2/4` даёт almost.

## Этап 2 — один ход целиком (≈2 ч)

1. `lib/llm.ts`: обёртка над Claude с prompt caching, таймаутами, retry 1, llmCache (record/replay), circuit breaker.
2. `lib/safety/`: preGuard (код), guardIn (Haiku), outputCheck (Haiku), CRISIS-шаблоны ru/uz.
3. `convex/turn.ts` — action `turn` по потоку из спеки. `convex/conductor.ts` — mutations переходов.
4. `ustozTurn` с промптом: Сократ, ответ не выдаёт, выбирает компонент.
5. Экран урока: задача → ввод → проверка → реплика Ustoz → анимация ожидания → компонент Лепёшка.

**Критерий:** ребёнок вводит `2/5` на `1/2 + 1/3`. Ustoz не сдаётся на «учитель сказал 2/5» и на «просто скажи ответ» (ru и uz).

## Этап 3 — путь до махалли (≈2 ч)

GOAL (Bobr спрашивает кнопками) → DIAGNOSE (фиксированные 6 проб) → PLAN → экран махалли. Дома меняют состояние через `houseMapper`. `/parent` подписан через `useQuery`.

## Этап 4 — «Научи Bobr» (≈2 ч)

TEACH_BOBR → copyCheck → judge (Sonnet, цитаты-подстроки) → BOBR_ATTEMPT (ответ подставляет код) или BOBR_QUESTION. При taught_bobr дом оживает и у ребёнка, и на `/parent` в ту же секунду. Это главный вау-момент, сделай его красиво.

## Правила работы

- После каждого этапа: `/verify`, затем субагент `reviewer` по диффу, затем коммит. Только потом следующий этап.
- Детерминированные модули пишет и тестирует субагент `tester` параллельно с UI, если харнесс это позволяет.
- Не выдумывай API Convex и Anthropic SDK: сверяйся с `convex/_generated/ai/guidelines.md` и документацией.
- Узбекский текст помечай `// TODO: вычитка носителем`.
- Ассеты Bobr и Хумо пока заглушки (цветные формы с подписью позы). Реальные PNG положим позже в `public/bobr/` с теми же именами поз: idle, think, confused, happy, aha, proud, sad, wave.
- Если застрял больше чем на 20 минут, остановись и напиши мне, в чём проблема и какие варианты.
